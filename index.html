The Last Fleet

A co-op, procedurally generated sci-fi FPS, built on the BRUTAL C# framework, .NET 10 and Vulkan 1.3. These pages are for the people who make what's in it: the models, the materials, the loot, the levels and the enemies.

Where to start

You make models. Start at Art in THE LAST FLEET. It covers what every model has in common (axes, scale, names, origins, materials) and links to a guide for each kind: the ship's hub, weapons, creatures, characters on a rig, and props. Every model's look comes from its surface materials.

You tune the game. Start at LastFleet Studio, the designers' tool: loot, guns, items, missions, levels, bodies, enemy behavior and materials, each edited with the game's own code running beside it. New to Studio? The Studio tutorials walk through real tasks in each mode, with a screenshot of every step. Adding content says what you can add as data and what still needs a programmer.

You write code. Architecture explains how the projects fit together, and the API reference is generated from the code's documentation comments.

How these pages are made

Every page is a Markdown file in the game's repository, under docs/, and the API reference comes from the source. The site is rebuilt whenever a change to either is merged, so what you read here matches the game on main.
