Remarks

This is a separate Jolt physics system from the simulation's JoltWorld, with its own copy of the level's boxes. Debris never affects gameplay, so it can run on the client, at frame rate, without determinism.

It's stepped on its own worker thread, with collision spread over Jolt's thread pool. Begin(float) starts a step and returns right away, and Complete() waits for it and shows its fragments. Each frame completes the step started the frame before, draws it, then begins the next one. So the step runs alongside the rest of the frame and the pieces are drawn a frame late, which is fine since they're only for show. Every other method waits for any running step first, so it's safe to call at any time from the thread that owns the world.
