How a round's push (a frame's Impact) moves what it hits, read from the loot data (content/defs/loot/impact.json). Default holds the values the game ships with. Pushes are in meters a second: the speed a round gives a body, before the body's friction takes it back.

Remarks

A round is one hit: its pellets' pushes on a body are added up before anything here is decided (see ShotResolutionSystem).
