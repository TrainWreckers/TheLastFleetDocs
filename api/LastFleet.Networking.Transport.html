Namespace LastFleet.Networking.Transport

Classes

ConditionedTransport

Wraps a real transport in a simulated bad network, for testing co-op over a LAN as if it were over the internet (--net-sim). Every message in either direction is delayed by the latency plus up to the jitter, and unreliable messages this machine sends are dropped at the given rate.

LoopbackNetwork

An in-memory network for tests and soak runs. Runs one host and any number of clients in one process, with latency, jitter and loss simulated deterministically from a seed and a clock the caller controls.

LoopbackTransport

One end of a LoopbackNetwork.

RakNetTransport

A transport using RakNet over UDP, from BRUTAL, for direct IP connections. The host listens on a port (forward it, or use a VPN such as Tailscale), and clients connect to its address.

Structs

LinkConditions

Conditions on a simulated link, applied in each direction.

NetEvent

One transport event. For Data, the message is the first Length bytes of the buffer passed to Poll.

Interfaces

ITransport

Moves messages between a host and its clients. The game only talks to this interface, so the transport can be RakNet (direct IP, for playtests), an in-memory network (tests, soak runs), or Steam networking later, without changing anything above it.
