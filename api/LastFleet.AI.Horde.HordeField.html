One flow field for the whole horde (design doc, "Horde simulation"). Instead of a path per swarmling, every spot in the level knows which direction leads to the nearest player.

Remarks

It works on two levels, like the soldiers' NavClusters. A search over clusters (each 4 m square of each floor) outward from the players gives every cluster the next cluster toward them. Inside a cluster, a small field, built the first time it's needed and then cached, gives each cell the step toward that next cluster. So hundreds of swarmlings cost one lookup each.

The grid is built with the mission's doors open, and here the floor in each doorway is its own cluster. A shut door (SetDoor(int, bool)) closes its cluster, so the field routes around it (or nowhere) and nobody walks through.

Deterministic, since the cached fields only depend on the grid. Not thread-safe.
