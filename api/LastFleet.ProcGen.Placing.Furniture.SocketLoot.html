The loot a group of sockets on a furniture model holds (the sockets field in props.json). Once a designer gives a group loot, the group belongs to them, so the placement rules don't put anything on it. Which of its sockets get filled is rolled with the level.

The loot a group of sockets on a furniture model holds (the sockets field in props.json). Once a designer gives a group loot, the group belongs to them, so the placement rules don't put anything on it. Which of its sockets get filled is rolled with the level.

public SocketLoot(string Group, int Fewest, int Most, float Chance, string? Items, string? Weapons, float WeaponShare, int Level)

Parameters

Group string

The sockets it fills. Top means every Socket_Top_* on the model.

Fewest int

The minimum number of sockets filled, when the piece gets any.

Most int

The maximum filled (capped at how many sockets the group has that can be reached).

Chance float

The chance (0 to 1) that the piece gets any loot.

Items string

The item table (content/defs/loot/items.json) that piles here are rolled from. Use RoomTable for the room's pile table (from loot.json, otherwise the mission's). Null for none.

Weapons string

The loot table (content/defs/loot/tables.json) that weapons here are rolled from. Use RoomTable for the room's cache table (from loot.json, otherwise the mission's). Null for none.

WeaponShare float

When both tables are set, the fraction of filled sockets that hold a weapon (0 to 1).

Level int

Item levels added on top of the deck's (and the room's), -10 to 10.
