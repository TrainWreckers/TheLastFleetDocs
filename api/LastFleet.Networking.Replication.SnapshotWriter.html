Remarks

Entity ids are the host's, and the client's replica uses the same ids, so events don't need translating. The layout is the same every tick, which is what lets SnapshotDelta send only what changed. It's split into Sections sections, and each list keeps its entities in the same positions (LastFleet.Networking.Replication.StableSlots). When an entity goes away it leaves a hole (an id of zero, then how many bytes to skip) instead of shifting everything after it.
