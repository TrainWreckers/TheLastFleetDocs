The Vulkan 1.3 renderer. It draws the scene in HDR with multisampling (the static world mesh, flat-shaded with a depth buffer and tinted per part, plus the horde, bodies, world-space effects and the gun in hand), then applies bloom and the tone curve into the swapchain, then draws the 2D overlay and textured UI (Dear ImGui) on top.

Remarks

Uses core Vulkan 1.3 features only: dynamic rendering (no render pass objects) and synchronization2 barriers and submits. Two frames are in flight, so the CPU records frame N+1 while the GPU draws frame N. Memory comes from VMA.

Call PreloadLoader() once, before the window is created, then construct the renderer on the main thread.
