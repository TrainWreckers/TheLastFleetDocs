A unit of simulation logic that runs once per fixed tick.

public interface ISimulationSystem

Remarks

Systems hold queries and configuration, never gameplay state. All state lives in components, so a world can be saved, replicated, checksummed and inspected without asking any system.

Iterate queries with query.Chunks and spans rather than ForEachEntity with a lambda. A lambda that captures the tick's delta allocates every tick, and the frame loop must not allocate.
