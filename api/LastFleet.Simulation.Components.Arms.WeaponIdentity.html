Parameters

Seed ulong

The roll's seed. It's also the weapon's spread and recoil seed.

Table uint

The loot table's hash (see LastFleet.Loot), or zero for a stock weapon.

Level ushort

The item level it was rolled at.

Rarity byte

The rolled rarity's rank (0 is Standard, going up). It's stored so the world can color a drop without rolling it again.

Properties

Generation

The loot data's generation when the weapon was rolled, meaning which parts existed at the time. 0 is for a weapon from before parts were added to the data.

public byte Generation { get; init; }

Remarks

The weapon rolls only from the parts in that generation, so adding a part later doesn't change any weapon a player already has.
