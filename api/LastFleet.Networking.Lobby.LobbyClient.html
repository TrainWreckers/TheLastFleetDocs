Class LobbyClient

Namespace
LastFleet.Networking.Lobby
Assembly
LastFleet.Networking.dll

A client in a host's lobby. It joins the lobby (checking the version), keeps track of who's there and which mission is set up, and tells the host when this player is ready. When the host starts a mission, it gives the game a RelayTransport to use for the mission's NetClient. The connection stays open between missions.
