A bot player that plays a mission on its own, for the Phase 3 gate (every seed has to be completable). It picks up the keycards in order (each one opens the gate to the next zone), walks to the terminal and holds Interact to start the hack, stays for it, then goes to extraction.

Remarks

It reads the mission from the world the same way a player would see it, and steers using the soldiers' navigation grid, writing the same PlayerCommand a keyboard does. It doesn't fight: the gate checks whether a level can be finished, not whether a bot can win it.
