The parts of a NavGrid's navigation that never change once it's built: each cell's column coordinates and the cluster map (NavClusters). There's one per grid (Topology), shared by every Pathfinder on it, which each keep only their own search memory.

Remarks

Nothing in it changes after it's built, so it can be read from any thread. Built of the floor as the grid was built: obstacles placed later and shut doors are each search's business, not the map's.
