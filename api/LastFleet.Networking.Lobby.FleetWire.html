Class FleetWire

Namespace
LastFleet.Networking.Lobby
Assembly
LastFleet.Networking.dll

Packs the host's fleet for joined players, and unpacks it on their side. The fleet goes whole, as its JSON compressed with Brotli: it changes a few times between missions, never during one, so there's nothing to gain from sending only what changed. Keeping to the save's shape means a new field on the fleet needs no network code.
