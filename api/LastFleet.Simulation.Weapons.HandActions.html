Works out what a character's hands are doing (HandAction) from its state. It checks, in this order: using an item, throwing a grenade, reloading, and a shot just fired. This is only for drawing the body; it doesn't read or change anything the simulation depends on.

Pack(in HandAction, uint, int)

Packs an action into the two bytes sent to clients. These stay the same for as long as the action lasts. The first byte holds the kind in the top three bits and the length in eighths of a second in the low five bits. The second byte is the low byte of the tick the action began on.

public static (byte Action, byte Began) Pack(in HandAction action, uint tick, int ticksPerSecond)

Remarks

The client works out how far through the action it is from those bytes (Unpack(byte, byte, uint, int)), so for example a reload costs no bandwidth between its start and end.
