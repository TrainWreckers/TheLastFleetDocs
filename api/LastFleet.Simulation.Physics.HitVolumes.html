Class HitVolumes

Namespace
LastFleet.Simulation.Physics
Assembly
LastFleet.Simulation.dll

The shapes shots can hit on a character: a capsule for the body and a sphere for the head. They're built from the same numbers as the collision capsule (so a crouched character is a smaller target) plus the hit shape (Shape). It's pure math, so hit detection is exact and deterministic no matter which physics engine is used.
