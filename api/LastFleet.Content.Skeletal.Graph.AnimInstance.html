Class AnimInstance

Namespace
LastFleet.Content.Skeletal.Graph
Assembly
LastFleet.Content.dll

One body playing an AnimGraph. It holds the body's parameters, which get set every frame before evaluation, and the per-body state the graph keeps between frames (each clip's clock, each synced blend's phase, which state each select node picked and how far it has faded to it). Create one per body; evaluating it doesn't allocate.

BodyOffset

Shifts the whole body above the legs, in model space (meters, +Y up), while the feet stay where they are. The graph's ground node moves the pelvis and has the legs reach back down to the feet. Used to hold a body in a pose its clips don't have (crouching lower behind cover, or rising to see over it). Zero for none.
