Namespace
LastFleet.ProcGen.Placing

A spot the mission needs in a room. A piece of furniture can stand in for it (Marker): when a built room's furnishing places that piece, it marks the spot where it stands, the same way a marker in a hand-made module does.

public enum MissionMarker

Fields

None = 0

No marker.

Terminal = 1

The objective terminal. It's hacked from in front.

Extraction = 2

The extraction point, where the squad gets picked up.

Key = 3

Where a keycard goes when no rule finds a place for it.

Battery = 4

A warship's gun battery, sabotaged from in front (a boarding action).

Reactor = 5

A ship's reactor, its power cut from in front of its console (a boarding action).

Suppression = 6

A warship's fire suppression controls, repaired from in front (a boarding action).
