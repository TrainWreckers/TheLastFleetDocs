Parameters

Id string

The id rules refer to it by: lowercase letters, digits and underscores.

Description string

A description for designers.

Kind PropKind

Its gameplay kind.

Size Vector3

Its box size in meters: width (X), height (Y) and depth (Z). The back is the side that goes against a wall. For a tank, the size of the template's largest tank kind is used, whatever is given here. For furniture with a model, the model's size is used (Size).

Color Vector3

The furniture's color, in linear space.

Breaks PropBreaks

What material the furniture breaks as when shot apart.

Name string

The name its level part is built under. Defaults to its id in title case.
