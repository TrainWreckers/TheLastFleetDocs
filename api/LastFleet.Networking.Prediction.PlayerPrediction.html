Client-side prediction for your own player. It runs your commands immediately through the same movement, mantle, loadout and weapon code the host runs, against the level's collision, so moving, turning and firing never wait for the host.

Remarks

Each snapshot includes your player as the host had it after a given command. Reconcile(NetClient) resets the predicted player to that state and replays the commands the host hadn't applied yet. If the result differs from what was shown (the host repeated a command because one arrived late, a soldier pushed you, a flinch), the difference goes into VisualOffset, which fades over a few ticks so a correction never snaps. A big correction (like a respawn) does snap. Health, grenades and anything else the host decides are copied from the host as they are.
