The host's lobby, where the squad gathers between missions. On its own it only holds the host. Once it's opened on a connection with Open(ITransport), friends can join, mark themselves ready, and see the mission the host has set up and what everyone is carrying.

Remarks

The connection stays open between missions. BeginMission(string, bool) gives each mission's NetHost a RelayTransport on top of it, and the lobby forwards mission messages to it until EndMission(string). Call Update() every frame, and before each mission tick's NetHost.Receive.
