Class ShutDoors

Namespace

Keeps a Pathfinder out of doorways that are still shut. The nav grid is built with every door open, so this blocks the mission's locked doors (except the ones the pathing agent can open), the spawn closet doors, and the doors through bulkheads shut for a seal (SealableDoor), which nobody opens. It only rebuilds when a door opens or shuts.
