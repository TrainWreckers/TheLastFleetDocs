Handles soldier weapon and kit drops. When a soldier (anything with a LootDrop) dies, it can drop a weapon where it fell, and next to it a medkit or ammo pack, or a weapon part (each with its own separate roll).

Remarks

The weapon is rolled from the SoldierLoot table for the gun the soldier carried (the table id with ".archetype" appended, for example "loot.station.soldier.machine_gun"), or from the base table if there isn't one for that gun. The chance and the roll come from the run's seed, the soldier's ID and how many soldiers have been rolled before, so the host decides and every client sees the same weapon.

This is a command system: it runs at the start of a tick and sees deaths from the previous tick. It doesn't allocate on ticks with no deaths; a drop allocates for its roll.
