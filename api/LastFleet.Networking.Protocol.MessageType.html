The first byte of every message.

public enum MessageType : byte

Fields

Hello = 1

Client to host: protocol version and player name. The first message after connecting.

Welcome = 2

Host to client: the client was accepted. Carries the player slot, entity and level.

Reject = 3

Host to client: the client was refused, with the reason. The host disconnects after sending it.

Input = 4

Client to host: the latest player commands, plus a few earlier ones in case packets get lost.

Snapshot = 5

Host to client: the state of the world at a tick.

Events = 6

Host to client: what happened on a tick (shots, hits, explosions, broken props, barks).

LobbyWelcome = 7

Host to client: the reply to a lobby hello, with the player slot the client was given.

LobbyState = 8

Host to client: who's in the lobby, whether they're ready, what they're carrying, and the next mission.

LobbyReady = 9

Client to host: whether the player is ready for the mission.

MissionStart = 10

Host to client: a mission is starting, with its level name. The client loads it and joins.

MissionEnd = 11

Host to client: the mission is over, with how it went. The client goes back to the lobby.

MissionLeave = 12

Client to host: the player is leaving the mission for the lobby. The others keep playing.

MissionRejoin = 13

Client to host: the player wants to rejoin the running mission.

FleetState = 14

Host to client: the whole fleet (its stores, ships, map and log), packed by FleetWire. Sent when a player joins and whenever the fleet changes, since everything at home is shared.

FleetRequest = 15

Client to host: a request about the shared fleet (set a course, upgrade the refinery, fabricate). The host checks it, carries it out, and sends everyone the fleet again.
