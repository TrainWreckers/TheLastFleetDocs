Interface ICollisionWorld

Namespace
LastFleet.Simulation.Physics

LastFleet.Simulation.dll

The collision the simulation needs: moving characters through the level and casting rays. This keeps the simulation headless and engine-free. LastFleet.Physics implements it with Jolt, and FlatGroundWorld is an infinite floor for tests and headless runs.

public interface ICollisionWorld

Remarks

Characters are identified by a handle greater than zero. The world owns their collision state (contacts, current shape), and the simulation copies the results into components every tick, so positions stay in the ECS and in the checksum.

Properties

GeometryVersion

Changes whenever what Raycast(Vector3, Vector3, float, out RayHit) can hit changes (a level part added, or turned off or back on), so an answer found by rays can be kept until it does. Worlds whose geometry never changes leave it at 0; a world whose does must change it, or what's kept goes stale.
