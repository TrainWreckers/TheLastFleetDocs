How a rule lays out its props as a group (the arrange field in rules.json): a row of pieces, or several rows, treated as a single spot for the rule's anchor. For example a galley's tables, a lab's benches back to back, or a dormitory's bunks.

Parameters

Columns (int Min, int Max)

The min and max pieces per row.

Rows (int Min, int Max)

The min and max number of rows (a single row has one).

Gap float

The space between pieces in a row, in meters (0 means touching).

Aisle float

The space between rows (or between back-to-back pairs of rows), in meters. Has to be wide enough to walk through.

Along ArrangementAxis

The direction the rows run in.

BackToBack bool

If true, rows come in back-to-back pairs facing outward, with the aisle between pairs.

Fill bool

If true, it uses as many pieces as fit, starting from the max and working down. Otherwise it uses a random count.

Remarks

Each placed arrangement counts once toward the rule's count. It's placed whole or not at all, it has to leave every path through the room open, and its aisles stay reserved as open floor afterward.

Fields

LeastAisle

The narrowest aisle people walk down, in meters. It's twice the soldier clearance (the AI's 0.4 m radius) plus one navigation cell (0.25 m), which is 1.05, rounded up to the next tenth on the half-meter placement grid (1.1).

public const float LeastAisle = 1.1
