Remarks

Plan coordinates are grid cells (4 m): X runs along a ship from its bow, Z across it, with the centerline at Z = 0, so mirroring is across Z = 0. Every choice is made in whole cells or with plain arithmetic, never a trigonometric function, so a seed covers the same cells on every machine.
