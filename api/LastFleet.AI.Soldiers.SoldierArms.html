Remarks

Which guns each kind of soldier carries, and how often, is set per variant in content/defs/ai/enemies.json. How a gun changes the way a soldier fights (its damage, the distance it keeps, how long it holds the trigger, the squad role it takes) is set on the weapon frame (Soldier, in archetypes.json).
