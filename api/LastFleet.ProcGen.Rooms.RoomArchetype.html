A kind of room the generator builds from designer data (archetypes.json). It sets the room's shape, the content tags it carries (which placement rules match on), the mission roles it can play, the surface style it's built and dressed in, and how it's furnished. A mission template lists the archetypes its built rooms are picked from, each picked by its weight.
