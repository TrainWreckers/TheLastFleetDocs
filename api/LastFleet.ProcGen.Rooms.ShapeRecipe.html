How a room's footprint is made (ShapeBuilder): its kind, how big its bounds can be, and how much of them it leaves out. Everything is in grid cells (4 m), picked from the seed within the given ranges.

public ShapeRecipe(ShapeKind Kind, (int Min, int Max) Width, (int Min, int Max) Depth, (float Min, float Max)? Cut = null, (int Min, int Max)? Lumps = null, float Chamfer = 0, IReadOnlyList<(int X, int Z)>? Cells = null)

Parameters

Kind ShapeKind

The kind of shape.

Width (int Min, int Max)

The min and max cells across its bounds (along X, before it's rotated).

Depth (int Min, int Max)

The min and max cells deep.

Cut (float From, float To)?

How much of a side a cut takes (an L's corner, a U's notch, how thin a T's or a cross's bars are), as a fraction from 0 (as little as the shape allows) to 1 (as much as it allows). If not set, anywhere in that range.

Lumps (int Min, int Max)?

For a blob, how many rectangles it's joined from (two to four if not set).

Chamfer float

How far the corners are cut at 45°, in meters along each wall (Sizes). Applies to every corner that has the room on one side only and no doorway on either wall. It isn't part of the footprint, which is whole cells; the room built on it cuts its own corners (ParametricRoom).

Cells IReadOnlyList<(int Min, int Max)>

A stamp's cells (Stamp), as a designer drew them: cell X and Z, with the minimum of each at 0. The width and depth are their bounds. Null for every other kind.
