Class GenerationSettings

Namespace
LastFleet.ProcGen.Missions

The settings a lobby can change on a mission template before a level is generated: how many decks, how many soldiers, how much loot, how many stories, and how many rooms are built from the seed. They're encoded in the level's name (Encode()), so every co-op peer generates the same level from the name alone.

The settings a lobby can change on a mission template before a level is generated: how many decks, how many soldiers, how much loot, how many stories, and how many rooms are built from the seed. They're encoded in the level's name (Encode()), so every co-op peer generates the same level from the name alone.

public GenerationSettings(int Zones = 4, int SoldierPercent = 100, int LootPercent = 100, int Stories = 2, int BuiltRooms = -1, string? CargoFocus = null, int CargoPercent = 100, string? Objective = null)

Parameters

Zones int

Number of decks, each behind a keycard gate (1 to 6).

SoldierPercent int

Soldier count as a percent of the template's (25 to 300).

LootPercent int

Loose and dropped weapons as a percent of the template's (0 to 300).

Stories int

How many stories the level can climb through (1 to 3).

BuiltRooms int

Rooms built from the seed (0 to 8), or -1 to use the template's own count.

CargoFocus string

The supply most of the cargo is, by item id (one of Cargo), or null for a mix.

CargoPercent int

Cargo crate count as a percent of the usual (0 to 300).

Objective string

For a mission laid out by a plan, what the squad comes for (one of Kinds), or null for the template's own pick.

Encode()

Returns the settings as a short string for a level's name, for example z4-s100-l100-f2-b4-cfuel-k150. The b part is left out for -1, c for a mix, k for 100, and o (the objective, odata) for the template's own pick.
