Namespace LastFleet.Rendering.Rays

Classes

RayGeometry

The level mesh as the rays see it: only the drawn parts (collision-only parts are left out), split into the geometries of the level's bottom-level acceleration structure. Parts that never disappear are merged into as few geometries as the mesh order allows, and are opaque, so a ray stops at them right away. Each part that can disappear (a prop that breaks, a door that opens, Gone) gets its own geometry and isn't opaque, so the shader can check every frame whether it's still there.

RayGeometry.Run

One geometry: a range of the mesh's indices, and the part it belongs to if that part can disappear (-1 if it's always there).

RayQualitySettings

RayTracingSupport

Whether a GPU supports ray tracing the way the renderer uses it (ray queries from compute shaders against acceleration structures). Checks the required extensions and features, and if any are missing, lists them for the log. NVIDIA RTX 20 series and later, AMD RX 6000 and later, and Intel Arc support it, and so does Mesa's software driver from version 25.

How much ray tracing work is done each frame when rays are enabled (LastFleet.Rendering.Rays.RayLighting; docs/plans/ray-tracing.md phase 11). Each level sets the expensive settings together (For(RayTracingQuality)).
