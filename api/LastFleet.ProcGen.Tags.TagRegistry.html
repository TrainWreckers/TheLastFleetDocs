Every tag a level's rules can use, each with its own id. Tags are dotted names that nest: room contains room.storage, which contains room.storage.cold, and a rule asking for room.storage also matches its children (TagSet, TagQuery).

Remarks

The registry holds the built-in tags (BuiltInTags) and the content's own tags (content/defs/procgen/tags.json), plus every parent those tags imply. Ids follow the ordinal order of the names, so the same tags always get the same ids no matter what order they were listed in. An id means nothing outside its registry.

Immutable, so one registry can be shared by every level generated from the same content.
