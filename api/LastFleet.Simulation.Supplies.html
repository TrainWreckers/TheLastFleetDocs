Namespace LastFleet.Simulation.Supplies

Classes

FlatUse

A fixed amount used every jump ("per": "jump").

FleetSupplies

The fleet supplies currently in play (SupplyDefinition). Once the loot data's supplies.json is put in play with Use(IReadOnlyList<SupplyDefinition>?), those are used. Otherwise it's the shipped ones (Shipped), which match the repository's data.

InContactUse

Used only while the Scourge is on the fleet ("per": "contact"). It's what fighting the Scourge off costs.

MessageShortage

Writes Text to the jump's log.

MoraleBonus

Raises morale by Amount. If Ship names a ship kind, it only applies while a ship of that kind is still flying.

MoraleShortage

Lowers morale by Amount, plus one more for every PerUnits units short. A PerUnits of 0 means there's no extra drop.

PeopleLostShortage

Kills PerUnit people for each unit short, taken from the transports first. The log names Cause as the cause, for example "hunger" gives "40 people died of hunger.".

PerDamagedShipUse

Used for each ship that's still flying but damaged ("per": "damagedShip"). It's what repairs cost.

PerPeopleUse

Used for each People people aboard ("per": "people"). If RoundUp is true, a partial group counts as a whole one (at one per 160 people, 161 people use two); otherwise it's dropped.

PerShipUse

Used for each ship that's still flying ("per": "ship").

ProduceBonus

Adds Amount of the item Item to the stores, like a farm's harvest. If Ship names a ship kind, it only applies while a ship of that kind is still flying.

RepairShipsBonus

Repairs every damaged ship by Amount condition, capped at full condition.

ShipWornShortage

One ship (never the flagship) loses PerUnit condition for each unit short. Message is logged, with the ship's name filled in for "{ship}".

ShortageEffect

Something that happens when the fleet runs short of a supply on a jump (the "short" list in supplies.json). It scales with how many units short the fleet is. Effects apply in order.

StockedEffect

Something that happens when the fleet has enough of a supply on a jump (the "stocked" list in supplies.json). Effects apply in order.

SupplyDefinition

How the fleet uses one of its supplies (content/defs/loot/supplies.json). It covers how much a jump costs (Use, with the parts added together), what happens when the fleet runs short (Shortage), what happens when it has enough (Stocked), and where the supply can be found.

SupplyUse

One part of how much of a supply a jump costs the fleet (the "use" list in supplies.json). All the parts are added together. Each one is a whole number of units.

WhileShipUse

Used while a ship of the kind Ship is still flying ("per": "shipAlive"). It's what that ship needs to keep working.
