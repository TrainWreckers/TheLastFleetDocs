Remarks

With Keys: (input, value) points joined by straight lines, and flat past the first and last point. Two keys at the same input make a step there, and from that input up the later key's value is used.

Without keys: it goes from Low to High as the input goes from From to To, clamped outside that range. If From equals To it's a step: high at that value and above, low below it.
