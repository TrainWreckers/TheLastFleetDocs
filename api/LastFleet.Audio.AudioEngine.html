Remarks

There's a fixed set of voices (VoicePool). Each voice is a source with a low-pass filter for sounds heard through walls. Spatial voices send to one shared reverb, set by the kind of space the listener is in. Sounds placed in the world fade with distance and get dulled by the air. Effects, interface and ambience each have a volume, under a master volume.

With no sound device (a server, or a machine with no output) it plays nothing and costs nothing. In offline mode (OpenOffline(SoundLibrary)) it mixes into memory instead of a device, which the smoke run and the tests use. Everything runs on the calling thread, and OpenAL Soft does its mixing on its own thread. Doesn't allocate after it opens.
