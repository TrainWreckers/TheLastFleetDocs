Namespace LastFleet.Simulation.Weapons

Classes

DestructionLog

The props that broke this tick. Cleared every tick. The client uses it to hide the props and spawn debris.

ExplosionLog

The explosions that went off this tick. Cleared every tick, like the HitLog. The client draws them.

HandActions

Works out what a character's hands are doing (HandAction) from its state. It checks, in this order: using an item, throwing a grenade, reloading, and a shot just fired. This is only for drawing the body; it doesn't read or change anything the simulation depends on.

HitLog

What this tick's shots hit: one record per shot, in firing order. Cleared every tick, so read it after Step() returns. The client draws hit markers, impacts and tracers from it, and co-op will send it to clients.

ImpactRules

How a round's push (a frame's Impact) moves what it hits, read from the loot data (content/defs/loot/impact.json). Default holds the values the game ships with. Pushes are in meters a second: the speed a round gives a body, before the body's friction takes it back.

ShotLog

The shots fired during the current tick. Cleared at the start of each weapon update, so read it after Step() returns. Hit detection will consume it once physics exists.

SoldierUse

How a frame changes the way a soldier fights with it (the frame's "soldier" data).

WeaponArchetype

The fixed traits of a weapon frame, the things that make an auto rifle an auto rifle. The stats on a WeaponProfile scale these values.

WeaponArchetypes

The weapon frames. Each one is an archetype from the loot data (archetypes.json) with its model file, how it fires, its fire rate, magazine, damage, spread and so on.

WeaponHandling

The gunplay model, Destiny style: trigger modes and exact cadence, magazines and reloads, aim down sights, spread and bloom, and recoil that kicks the view and partly recovers. One call advances one weapon by one tick.

WeaponStatsResolver

Turns a designer-facing WeaponProfile into the physical WeaponStats the simulation uses.

WeaponTraitRules

The tuning numbers behind WeaponTraits, read from the loot data (content/defs/loot/traits.json). Default holds the values the game ships with. Each trait should be noticeable in a fight but never decide one on its own.

Structs

BreakRecord

A prop that broke this tick.

DamageProfile

How much a shot hurts, and pushes, at a given distance and hit location.

ExplosionRecord

One explosion and what it did.

HitRecord

Where one shot ended and what it did.

ShotRecord

One fired round, ready for hit detection.

TriggerGroup

What a gun's trigger group (its trigger part) does to how it fires: the modes it can be switched between and the one it starts in, and its rate of fire and burst against the frame's. The default (no modes) leaves the frame's own fire mode, rate and burst, as a gun rolled before triggers were parts has.

WeaponProfile

A weapon as designers and the loot generator see it: an archetype plus Destiny-style 0–100 stats, and three scales on the frame's own values that weapon parts can nudge (for example a coil barrel hits harder, a drum holds more, a scope zooms further). Parts and affixes adjust these, never the raw physical values.

Enums

SoldierRole

The squad role a frame gives the soldier carrying it, if the squad has that role to fill.

WeaponFiring

How a frame's rounds travel. Each value is a firing code path in the game, picked by the frame's "firing" data.
