Namespace LastFleet.AI.Soldiers

Classes

SoldierAiSystem

Barks, and picking an intent through utility scoring.

SoldierArms

Picks the guns soldiers carry. Each soldier's gun is derived from its seed, so the host and every client agree.

SoldierSpawner

Spawns soldiers with their AI. Each one is an enemy variant (EnemyRoster), which sets its body, guns, faction and the behavior it uses.

SoldierTuning

How tough soldiers are to fight. Difficulty comes from reactions, aim and coordination, never from health (see the Difficulty table in the design doc).

SoldierTunings

Soldier tuning per faction: the values every faction shares (Shared), plus separate values for any faction that differs (For(FactionId)).

TuningField

One soldier tuning value (SoldierTuning): its key in tuning.json, how it's shown and edited, and how it's read from and written to a tuning. The developer overlay, LastFleet Studio and the file all go through All, so they always agree on which fields exist.

TuningFields

Every soldier tuning value (SoldierTuning), grouped the way they're edited. This is the list of what tuning.json can hold and what the developer overlay and LastFleet Studio show, with slider ranges and a description of each.

Structs

CoverWork

What choosing cover cost in a tick (LastCoverWork): how many choices, the cover points they looked at, the claim checks against other soldiers' cover, and the ray tests. For the developer overlay and the headless benchmark; the simulation never reads it.

SightWork

What looking for enemies cost in a tick (LastSightWork): how many soldiers looked, the characters they looked over, how many enemies were in view and range, and the sight lines cast to them. For the developer overlay and the headless benchmark; the simulation never reads it.

Enums

AiSection

A part of SoldierAiSystem's tick, timed separately (LastMilliseconds(AiSection)). Together they are the whole tick.

PathPurpose

What a soldier's path search was for, to count the searches by (PathSearches).

TuningKind

The type of value a TuningField holds, which decides how it's saved and edited.
