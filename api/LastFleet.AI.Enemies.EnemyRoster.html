The enemy variants (content/defs/ai/enemies.json), and which one spawns where. A level's squads, the mission's reinforcements, the director's patrols and the Choir's squads each pick a variant using the weights the variants set for that source. The pick comes from the squad's seed, so it's the same on every machine.

Remarks

Everything that spawns shares the roster in play (InPlay). The game sets it when it loads the data, and LastFleet Studio sets it as the data is edited. Default is the shipped file, embedded in the AI assembly.
