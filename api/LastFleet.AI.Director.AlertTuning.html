Tuning for the station's alert level (Alert, 0 to 1): how it rises with time and noise, how little it drops, and how it affects the Director and the horde. This is a mission template's "alert" section.

public AlertTuning(float PerMinute = 0.05, float PerFightSecond = 0.003, float PerNoiseSecond = 0.002, float HackJump = 0.15, float Keep = 0.75, float Fade = 0.01, float Aggression = 2.5, float PatrolBonus = 2, float CapBonus = 3, float HordeAt = 0.6, float Elevated = 0.35, float High = 0.65, float Lockdown = 0.9, float SweepRooms = 6, float NudgeSeconds = 45, float BackOffSeconds = 25, float Floor = 0)

Parameters

PerMinute float

Increase per minute on the level, no matter what the squad does.

PerFightSecond float

Increase per second that a soldier is fighting.

PerNoiseSecond float

Increase per second for each tank pumping and each cargo pod drone inbound.

HackJump float

Immediate increase when the hack starts.

Keep float

Fraction of the peak alert that it never drops below.

Fade float

Decrease per second while nobody is fighting and the squad is calm.

Aggression float

At full alert, the Director's wait times are divided by this (on top of the run's pacing).

PatrolBonus float

At full alert, this many extra soldiers per patrol.

CapBonus float

At full alert, this many extra patrol soldiers can be alive at once.

HordeAt float

From this alert level on, the run's hordes can come during infiltration, regardless of deck.

Elevated float

Alert level where the station goes on alert (amber lights, the PA).

High float

Alert level where it goes on high alert.

Lockdown float

Alert level where it locks down (red lights, and patrols come without waiting for quiet).

SweepRooms float

At full alert, how many extra rooms a hunter sweeps before standing down (it sweeps two when calm).

NudgeSeconds float

When calm, how long between the Director nudging a garrison soldier toward the squad's area. Starts from the first stage, and happens three times as often at full alert.

BackOffSeconds float

How long hunters can crowd the squad without a fight before the Director pulls them off.

Floor float

What the alert never drops below (a boarded warship at battle stations); 0 for none.
