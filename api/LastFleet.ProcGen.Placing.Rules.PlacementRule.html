A rule for placing props (rules.json): which props, in which rooms, where in the room, how many, and what space they have to leave clear. Rules run highest Priority first, each one in every room it applies to.

public PlacementRule(string Id, string Description, IReadOnlyList<WeightedProp> What, TagQuery? Where, PlacementAnchor Anchor, PlacementAnchor? Fallback, PlacementCount Count, float Clear, float Spacing, int Priority, bool Blocks, float Interaction, bool Required)

Parameters

Id string

Its name: lowercase letters, digits and underscores.

Description string

What it's for, for designers.

What IReadOnlyList<WeightedProp>

The props it places. One is picked by weight for each spot.

Where TagQuery

The rooms it applies to, by tag (role., layout. and the content's own tags).

Anchor PlacementAnchor

Where in a room it looks for spots.

Fallback PlacementAnchor?

Where to look in a room where the anchor finds no spots at all. Null for nowhere.

Count PlacementCount

How many a room gets. Not used for props the mission counts (keycards and tanks).

Clear float

The space kept clear around each of its props, in meters, from other props and from anything else in the room.

Spacing float

The minimum distance between two of its props in a room, in meters, center to center.

Priority int

Higher-priority rules place first.

Blocks bool

If true, its props block movement, so each one has to leave every path through the room open.

Interaction float

The open floor kept in front of each of its props for using it, in meters. It has to be reachable from the room's doorways. 0 for none.

Required bool

If true, every room it applies to has to get at least the minimum count. A built room that can't is rebuilt from another seed, and a shortfall in a level is reported.
