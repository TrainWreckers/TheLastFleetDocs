Table of Contents

Namespace LastFleet.Content.Models

Classes

LibraryModel

One model in the ModelLibrary: a top-level object from a file in content/props or content/weapons.

ModelColliders

What each model is collided with (ColliderKind), read from colliders.json next to the models (content/props). Kept apart from the models themselves and from the rules that place them, since the same model is placed by many rules.

ModelFile

One .gltf file in the ModelLibrary, and the models in it.

ModelLibrary

Every model made in Blender for the game: each top-level object of each .gltf in content/props and content/weapons, named "file/Object" (ModelId), with its paint slots.

ModelPart

One top-level object in a parts file (ModelParts): its triangles and empties, in its own space. The origin of that space is the attach point.

ModelParts

Loads a glTF file of parts (weapon parts made in Blender). Each top-level object is a part, with its meshes and empties in its own space.

PaintSlots

The naming rules for model materials and color (see docs/blender/props.md and docs/blender/weapons.md). A material named Paint_<Name> is a PaintSlot whose color is set by the data, defaulting to the material's own color. A few names are colored by the game (a prop's Glint, a gun's Body). Any other material keeps its own color.

Structs

ModelId

The id data uses to refer to a model: its file in content/props or content/weapons (without .gltf) and the top-level object in it, written as "file/Object" (items/Medkit, auto_rifle/Receiver).

ModelMarker

An empty inside a ModelPart, for example a socket, a muzzle or an aim point.

ModelMaterial

A material on a model: its name, base color and which library material it maps to.

ModelTriangle

A triangle of a ModelPart, in the part's own space, with the material it uses.

PaintSlot

A part of a model whose color is set by the data. In Blender it's a material named Paint_<Name> (see PaintSlots).

Enums

ColliderKind

What a model is collided with wherever it's placed (content/props/colliders.json, ModelColliders).

ModelKind

Which folder a model in the ModelLibrary comes from. This decides which game colors it can use.

PartShape

The body a level part with one (HasBody) is collided with, from its triangles. Rays always hit the triangles themselves.

PartUsage

Whether a part is drawn, collided with, or both.
