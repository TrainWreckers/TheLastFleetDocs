Namespace LastFleet.Content.Skeletal.Graph

Classes

AnimAction

A one-shot animation a body plays on top of whatever else it's doing (like Unreal's montage played into a slot), for example a reload, a throw or a shot's kick.

AnimGraph

A body type's animation graph, read from content/anim/<id>.json. It has the parameters it reads, and a tree of nodes (clips, blend spaces, selects, masked layers, additives, and IK for reaching, looking and foot placement) that turns those parameters into a pose. It's shared by every model of its rig.

AnimInstance

One body playing an AnimGraph. It holds the body's parameters, which get set every frame before evaluation, and the per-body state the graph keeps between frames (each clip's clock, each synced blend's phase, which state each select node picked and how far it has faded to it). Create one per body; evaluating it doesn't allocate.

AnimParameter

A number an AnimGraph reads. The code that knows the body's state (the client's bridge from the simulation) sets it for each body every frame. Flags are numbers too: 1 for on, 0 for off.

AnimPlayer

An AnimGraph bound to a model's skeleton and the rig's clips. It poses any number of bodies (each an AnimInstance), one at a time, without allocating. Not thread-safe.

ClipChoice

Decides which actual clip plays for each clip a graph names, for one grip style and one enemy variant (like Unreal's per-item animation layers, the way Lyra gives each weapon its own). The graph stays a single template for every body of its type, and whoever plays it swaps in their own clips. Created by Choose(string?, IReadOnlyDictionary<string, string>?) and assigned to a body's Clips.

ClipEvent

An event defined in a graph (like Unreal's notify). It marks a moment on a clip node (in seconds into the clip) or in an action (as a fraction, 0 to 1), and says what happens when a body passes it: a sound to play, an effect to show, and where on the body.

Structs

AnimEvent

A named moment in a clip (a footstep, the magazine coming out) that an AnimInstance passed during a frame.

Interfaces

IAnimWorld

What a body's IK nodes query from the world while its graph plays: where its targets are (the grips of the gun it holds) and where the ground is under its feet. Everything is in the body's model space: feet at the origin, +Y up, facing -Z. The game passes this to Evaluate(AnimInstance, float, Pose, IAnimWorld?). Without one, IK nodes do nothing.
