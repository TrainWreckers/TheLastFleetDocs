Namespace
LastFleet.Rendering.Lighting

A shadow map for this frame. Its tile in the frame's atlas matches its index in the frame's list. The level part of the map is cached at CacheSlot and only redrawn when Refresh is set (first use, or something in its room changed, like a prop broke or a door opened). It's drawn from the level index ranges ShadowRanges[First .. First + Count]. Characters move, so they're drawn on top every frame when Characters is set.
