FrameWaitLimit

The longest a frame waits for the GPU to finish an earlier frame, or for the display to hand back an image, before the frame is skipped (PresentationPaused). Window events are pumped while it waits, so the window stays responsive. A display that's asleep can hold on to images indefinitely. InfiniteTimeSpan never skips a frame, which smoke runs need since they count every frame.
