How an open breach (HullPull) drags whoever can see it: like a wind, a drift added to where they move each tick (CharacterBodySystem), so ground friction doesn't eat it and running away still counts. It's strongest at the breach, falling off evenly to nothing at its reach, only in front of the wall it's in and only in sight of it. The same on the host and in a client's prediction, which runs the same body step.
