Class AnimGraph

Namespace
LastFleet.Content.Skeletal.Graph

A body type's animation graph, read from content/anim/<id>.json. It has the parameters it reads, and a tree of nodes (clips, blend spaces, selects, masked layers, additives, and IK for reaching, looking and foot placement) that turns those parameters into a pose. It's shared by every model of its rig.

Remarks

Code that knows a body's state sets the parameters (the client's bridge from the simulation). The graph never refers to what the body is doing in the game, and the game never refers to a clip. An AnimPlayer plays it, with one AnimInstance per body.
