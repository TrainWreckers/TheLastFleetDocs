Remarks

It covers the fraction of rooms on a loop, the fraction that are dead ends, the longest chain of rooms leading to a dead end, how far the squad walks along the mission's route (the insertion, each keycard, the objective, extraction), and how much of that is backtracking. Spawn closets don't count as rooms here.

SkippableLocks(LevelLayout)

Returns the locks in layout that a squad could get past without the thing that opens them. For each gate, it checks whether any room beyond it can be reached with that gate shut (every other gate open, and each one-way shortcut opening only once its side is reached). Empty for a level that always puts its keys before its locks.
