Namespace LastFleet.Content.Meshes

Classes

BoxFit

Detects whether a mesh part is a box, possibly rotated. That's the only shape level collision supports.

MaterialColors

Works out the color a glTF material is drawn in: its base color plus its emission times the emission strength (KHR_materials_emissive_strength, which Blender exports when Emission is stronger than 1). This lets a lamp, a screen or an engine glow be brighter than white, which the renderer shows as glowing.

MeshData

A static, world-space triangle mesh, stored as an indexed triangle list with counter-clockwise front faces.

SmoothNormals

Computes smoothed normals for the corners of flat triangles, used for smooth materials' highlights (VertexSurface).

VertexSurface

Packs a vertex's surface data into 32 bits, the way the shaders read it. The lowest byte is the library material (MaterialLibrary). For a smooth material, the next three bytes hold the smoothed normal as a signed byte each for x, y and z. A zero normal means there isn't one, and highlights follow the face like everything else.

Structs

MeshPart

A named range of triangles inside a MeshData. It's one glTF node, such as one wall or one crate.

MeshVertex

One vertex of a static world mesh, laid out exactly as the GPU reads it (40 bytes).
