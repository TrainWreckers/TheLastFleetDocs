Archetypes IReadOnlyList<string>

The archetype ids it fits. Empty means all.

Mods IReadOnlyList<StatRange>

The stat changes it applies.

Model string

The model it uses. Either a name in the frame's part file (Barrel_2_Heavy), or just the shape those names end with (Heavy) so one part picks its look on every frame. None means nothing is shown in the slot. For an optic it's the sight type (Iron, RedDot, Holographic, Scope). Null picks one based on the id.

Paint IReadOnlyDictionary<string, Vector3>

Colors for the model's paint slots (materials named Paint_<Slot>), keyed by slot. Slots not listed keep the model's own color. Null for none.

Reticle string

An optic's reticle (Reticles). Red dot and holographic sights use dot, ring or chevron; scopes use duplex, mildot or chevron. Null uses the sight's default.

Traits WeaponTraits

Extra effects beyond its stat changes, for example a suppressor's Suppressed.

Since int

The loot data generation the part was added in (0 for parts that existed before generations). A weapon only rolls from parts of its own generation or earlier (Generation), so adding a part to a pool doesn't change any weapon a player already has.

SecondZoom float

An optic's second zoom level, toggled with a key. It's the multiplier on the gun's zoom (2 for a variable scope, 3 for a magnifier behind a red dot). 1 means there's only one zoom.

Trigger TriggerGroup?

A trigger part's fire modes (the first is the one a gun starts in), rate and burst. Null for every other slot.

EyeRelief float

A scope's: how far its eyepiece sits from the eye when aimed, in meters; nearer, its window fills more of the view. 0 for the default (DefaultEyeRelief).
