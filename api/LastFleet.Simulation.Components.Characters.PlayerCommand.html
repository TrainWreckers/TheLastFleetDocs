Remarks

In co-op, clients send these to the host and the host applies them on the matching tick, so the same type carries local input now and networked input later. The client writes a fresh command before each tick. Buttons are sent as held state, not presses. The simulation works out presses itself, so a lost or repeated packet can't fire a semi-automatic weapon twice.
