Namespace LastFleet.AI.Navigation

Classes

NavClusters

A coarse map over a NavGrid for long paths. Each 4 m square of each floor is split into clusters of walkable cells that connect inside the square, and clusters are linked wherever a link or a drop crosses from one to the next.

NavGrid

A layered navigation grid over a level. Each column of the grid holds every floor in it, from the ground up to mezzanines, catwalks and stair landings, so floors stacked over each other are all navigable.

NavTopology

The parts of a NavGrid's navigation that never change once it's built: each cell's column coordinates and the cluster map (NavClusters). There's one per grid (Topology), shared by every Pathfinder on it, which each keep only their own search memory.

Pathfinder

A* over a NavGrid. Eight-connected with no corner cutting, goes between floors via stairs and ramps and down ledges via drop links, then smooths the result into straight segments. All working memory is allocated up front, so finding a path doesn't allocate.

ShutDoors

Keeps a Pathfinder out of doorways that are still shut. The nav grid is built with every door open, so this blocks the mission's locked doors (except the ones the pathing agent can open), the spawn closet doors, and the doors through bulkheads shut for a seal (SealableDoor), which nobody opens. It only rebuilds when a door opens or shuts.

NavGridSettings

How a NavGrid is sampled from the level.

PathSearchStats

Counts of path searches, summed over some period (one tick, a run): how many, how many found no way, how many fell back to the whole grid, how many cells they expanded and how long they took. For the developer overlay and the headless benchmark; the simulation never reads it.
