Remarks

A body type's graph lists its actions. Each one has the clip it plays, the part of the body it covers, and how it fades in and out. The graph's slot node plays whichever action the body is doing (Play(int, float)). The clip runs from start to end as the action goes from 0 to 1, so it lasts as long as the action does (a reload gets stretched to the gun's reload time).

The game uses the same action names as the simulation (reload, throw, fire, use). If a body has no action with that name, nothing plays.

Events (for example a grenade being released) are placed at a fraction of the action from 0 to 1. That way they stay in the right place no matter how long the action runs or which clip a grip swaps in. The slot fires each event as the action passes it.
