A rig's clips (content/anim/<rig>.gltf: the armature and its actions, made in Blender), bound to a skeleton by joint name so every model of the rig can play them. Channels for joints the skeleton doesn't have are dropped.

Remarks

When bound with the rig, each bone's translation follows its RigTranslation (like Unreal's translation retargeting), so a model built longer or shorter than the clips' armature keeps its own build while they play.

Fields

MaxRestTurnDegrees

How far a model's joint can be rotated at rest from the clips' armature, in degrees. Clips rotate each joint relative to its rest pose, so a joint pointing a different way would bend the wrong way.

Load(string, Skeleton, Rig?)

Loads the clips in path for skeleton, which is a model of rig. Each joint's translation follows its rig bone's setting (the model's own, the clip's, or the clip's scaled to the model), and Problems lists any joint rotated at rest away from the clips' armature. With no rig, every joint uses the clips' translations.
