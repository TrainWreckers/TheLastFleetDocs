Remarks

Timed stat changes count down and expire. The passive effects of the items each player holds (Passive, counted once per item kind) are added to the running changes, and the totals are written where the game reads them (SpeedChange, DamageTakenChange, ReloadSpeedChange). The shield is whichever is stronger out of the used one and the held ones, and it regenerates after its delay without damage. Going down clears everything: stat changes, shield and armor.

Runs after the life system (which tracks time since damage) and before movement, so a change applies on the same tick it's made. Only the host runs it; each client gets its own player's result in every snapshot. Doesn't allocate.
