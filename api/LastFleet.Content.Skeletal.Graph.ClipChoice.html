Decides which actual clip plays for each clip a graph names, for one grip style and one enemy variant (like Unreal's per-item animation layers, the way Lyra gives each weapon its own). The graph stays a single template for every body of its type, and whoever plays it swaps in their own clips. Created by Choose(string?, IReadOnlyDictionary<string, string>?) and assigned to a body's Clips.

Remarks

For a clip the graph names, say Idle, the clip that plays is picked like this:

  1. the grip's own version, for example Pistol_Idle for grip pistol (GripClip(string, string)), if the rig has that clip; otherwise the graph's clip;
  2. then, if the variant renames that clip ("Idle": "Lancer_Idle", or "Pistol_Idle": ... for its pistol stance), the renamed clip, if the rig has it.

So a variant only overrides a grip clip by naming it explicitly, and a clip the rig doesn't have is never picked.
