Parameters

Name string

The clip name, for example Run, Idle, WindUp, Bite, Stagger or Death.

FirstFrame int

Index of the clip's first frame in the model's frame list.

FrameCount int

Number of frames: the clip's length at FramesPerSecond, plus one for the end frame (for a loop, the last frame is the same as the first).

Seconds float

Length of the clip in seconds.
