Parameters

A Vector3

First corner (corners go counter-clockwise seen from outside).

B Vector3

Second corner.

C Vector3

Third corner.

Material string

The material name, with Blender's duplicate suffix (.001) stripped. Empty for none.

Color Vector3

The material's base color.

Node string

The mesh object the triangle belongs to, with Blender's duplicate suffix stripped. Its name can say what it's for, for example a station prop's Shell_NoCollision (see UsageFromName(string)). For the part's own mesh, this is the part's name.

SurfaceA uint

The surface data for A: the matching library material (MaterialLibrary) and, for a smooth material, the corner's smoothed normal (VertexSurface).

SurfaceB uint

The surface data for B.

SurfaceC uint

The surface data for C.
