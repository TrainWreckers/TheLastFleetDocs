A type of enemy soldier (content/defs/ai/enemies.json): its body, guns, faction, the behavior it uses, and where it spawns. Every soldier in a squad is the same variant.

public EnemyVariant(string Id, string Name, string Description, string Behavior, FactionId Faction, float Health, float DamageScale, int Grenades, float RunSpeed, float SprintSpeed, bool DropsLoot, IReadOnlyList<(string Frame, float Weight)> Weapons, IReadOnlyList<float> Spawns, string Body = "humanoid", string Model = "soldier", IReadOnlyDictionary<string, string>? Clips = null)

Parameters

Id string

Its id.

Name string

Its display name, for designers and the debugger.

Description string

A one-line description.

Behavior string

The id of the behavior it uses (a behavior file in content/defs/ai).

Faction FactionId

Which side it's on: the station's soldiers, or the Choir.

Health float

Its health.

DamageScale float

Multiplier on its guns' damage (soldiers hit much less hard than players).

Grenades int

How many grenades it carries.

RunSpeed float

Running speed, in meters per second.

SprintSpeed float

Sprinting speed, in meters per second.

DropsLoot bool

True if it drops a weapon or parts when it dies.

Weapons IReadOnlyList<(string Type, float Weight)>

The guns it can carry, by frame id (an archetype in archetypes.json), each with a pick weight.

Spawns IReadOnlyList<float>

How often a squad from each source is this variant, indexed by EnemySource. 0 means never.

Body string

Its body type: the animation graph its body plays (content/anim/<body>.json), on that graph's rig. Only rendering reads this; the hit shapes come from the simulation.

Model string

The model it's drawn with (content/characters/<model>.gltf), on its body's rig.

Clips IReadOnlyDictionary<string, string>

Clip overrides that replace its body's clips, by name ("Idle": "Lancer_Idle"; "Pistol_Idle": ... for its pistol stance). Only rendering reads these. Empty for none.
