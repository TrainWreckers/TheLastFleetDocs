How a room's structure is built and how it looks. The generator builds the walls, floors and the rest from the room's structure markers using its style (LastFleet.ProcGen.Styles.StyleBuilder), and dresses it the same way (ceilings, trims, ducts, lights), so designers never have to model a wall. Styles are designer data in content/defs/procgen/styles.json. A style can inherit anything it doesn't set from another style (its base), and ultimately from Station.

Builtins

The built-in styles, used when there's no styles.json and for any that styles.json leaves out. That's Station plus the halls of the default deck themes (Defaults): ribbed maintenance ways lit from under grated floors with no ceiling panels, a bright colonnaded concourse, arched cargo halls in sodium light with hazard-yellow trim, and labs with slim ribs, clean walls and cool cyan trim.

Station

The station's own style, matching how rooms were built before styles existed: grey painted walls on a worn metal deck, a baseboard in the deck color and a stripe in the room color, a duct and two pipes, and ceiling panels with a few dead or flickering. A hall in this style is plain with nothing along it. Every style ultimately inherits whatever it doesn't set from this one.
