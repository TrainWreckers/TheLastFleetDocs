The DLSS quality mode: how far below the display's resolution the path tracer renders before DLSS (Super Resolution, or Ray Reconstruction, which denoises as it upscales) brings it up to the display's. Named as NVIDIA's RTX UI guidelines name them. Dlaa renders at the display's resolution and only uses DLSS to clean up the image.

public enum DlssMode

Fields

Off = 0

No DLSS: the path tracer renders at the display's resolution with its own denoiser.

Dlaa = 1

DLAA: native resolution, DLSS as the anti-aliaser (and the denoiser, with Ray Reconstruction).

Quality = 2

Quality: about two thirds of the display's resolution on each axis.

Balanced = 3

Balanced: about 58% on each axis.

Performance = 4

Performance: half on each axis.

UltraPerformance = 5

Ultra Performance: a third on each axis, for 4K and above.
