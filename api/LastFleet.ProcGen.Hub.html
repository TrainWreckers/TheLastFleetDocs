HubLayout

The ship's hub as loaded by Load(string, HubStations?): the deck's mesh, where the squad comes in, and where each station is used from.

HubLevel

The hub between missions: the hangar deck of the fleet's ship, open to space along one side behind its shield. The squad's dropship sits on its pad. Along the walls are the mission console (pick and launch the next mission), the needs board (what the fleet has and what it's short of), the armory bench (weapons, parts, the pack) and the star map table. It's a hand-built level made in Blender (content/modules/hub/hangar_deck.gltf, docs/blender/hub.md), so it's the same on every machine.

HubStationRule

One of the ship's stations as data (content/defs/hub.json): which screen it opens, which markers in the hub's model stand for it, what its prompt says, and whether the deck must have one.

HubStations

The ship's stations as data (content/defs/hub.json, edited in Studio's Missions mode under Ship's hub): for each screen, the markers in the hub's model that stand for it and the prompt shown there. A new place to use a screen from is a marker in Blender and its name here; what each screen does is code.
