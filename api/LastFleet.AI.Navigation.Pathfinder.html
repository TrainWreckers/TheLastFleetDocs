A* over a NavGrid. Eight-connected with no corner cutting, goes between floors via stairs and ramps and down ledges via drop links, then smooths the result into straight segments. All working memory is allocated up front, so finding a path doesn't allocate.

Remarks

What never changes (cell coordinates, the cluster map) is the grid's Topology, shared by every pathfinder on it; each pathfinder holds only its search memory, about BytesPerCell bytes a cell. Not thread-safe, so use one instance per thread. The AI runs on the simulation thread.

BytesPerCell

Search memory a pathfinder holds per grid cell, in bytes: costs, parents, stamps, the heap, the shut-door marks, the scratch path and which part of the level each cell is in (LastFleet.AI.Navigation.Reachability). The grid's topology is shared, not counted here.

Remarks

Cheap when the goal can be reached (a search over clusters); otherwise it looks over the floor around it. A drop can't be climbed back, so only what can be got to by going down drops counts.
