Which phase a mission is in (see the design doc, "Mission structure").

public enum MissionPhase : byte

Fields

Infiltrate = 0

Find the keycards, open the locks, reach the terminal and start the hack.

Hack = 1

The hack runs while the squad holds the terminal's room. Reinforcements come in waves.

Extract = 2

The hack is done. Everyone still standing heads to the extraction point.

Succeeded = 3

The squad got out.

Failed = 4

Everyone was down or dead at the same time.

LeftEarly = 5

The squad left early on the docked dropship without what the fleet needed. They got out with what they carried, but the mission isn't won. (Leaving early with what the fleet needed counts as Succeeded.)
