Remarks

This is a constraint search over the mission graph, in the style of wave function collapse. Each room's domain starts as the types that can play its role. The insertion, keycard rooms, the objective, extraction and transit are pinned to the kit's own rooms, because they need the kit's markers. Every other room can be the kit's own or any archetype that plays its role, each weighted (the kit gets KitShare, and the archetypes split the rest by their weights). Rules then narrow the domains:

  • An adjacency rule, or a distance rule's minimum, is kept arc consistent between each pair of rooms it constrains.
  • A count rule rules out its rooms once its scope has hit the maximum, or forces them once only the minimum is still possible.
  • A distance rule's maximum rules out an A room that has no possible B room close enough.
  • Once the level's archetype budget is spent, no other archetype is picked.

Then the room with the lowest entropy (ties broken by node id) gets a type picked by weight, and the rules narrow again. When a domain empties, the search backs up and tries the next type, within a step budget. Every contradiction hit is traced, so a rule set that can't be satisfied reports why instead of hanging.
