Lag compensation for co-op: remembers where every character was at the end of each recent tick, so a client's shot is tested against the characters where that client saw them, not where they have moved since.

Remarks

A client draws others InterpolationTicks behind the newest snapshot, and its command reaches the host later still. The host sets each client's view tick (SetViewTick(int, double)) when it applies that client's command, and ShotResolutionSystem calls TryRewind(int, int, out Vector3, out MovementState) for each character a shot might hit. Add this system last, so it records where everyone ended up at the end of the tick. Rewinding is capped at MaxRewindTicks, so a client with a worse connection than that has to lead its targets.

Remarks

Swarmlings aren't recorded in this history. A client only gets some of them in each snapshot and keeps moving the rest along their path, so it sees them slightly off from anywhere they actually were. Its shots are tested against what it was shown.
