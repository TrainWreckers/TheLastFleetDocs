Remarks

The simulation always advances in identical steps, which keeps movement and physics stable at any frame rate and gives networking and replays a shared notion of time. The renderer uses Alpha to interpolate between the last two ticks so motion stays smooth on a 144 Hz display with a 60 Hz simulation.

Parameters

ticksPerSecond int

Simulation rate. The design targets 60 Hz.

maxTicksPerAdvance int

The most ticks one frame can run. After a long stall (a breakpoint, a loading hitch) the clock drops the backlog instead of trying to catch up, because catching up would make the next frame even slower.
