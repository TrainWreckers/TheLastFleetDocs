Play(int, Vector3, float, float, float)

Plays cue cue at position. A cue that isn't placed in the world plays as an interface sound instead.

void Play(int cue, Vector3 position, float gain = 1, float muffle = 0, float delay = 0)

Parameters

cue int

The cue's id in the library.

position Vector3

Where the sound happens.

gain float

Loudness, applied on top of the cue's own.

muffle float

0 is clear, 1 is heard through walls (quieter and dull).

delay float

Seconds before it starts, since sound takes time to arrive.
