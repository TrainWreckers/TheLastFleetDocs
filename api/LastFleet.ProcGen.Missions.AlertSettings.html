How a mission's station alert level builds up (its template's "alert"): how it rises over time and with noise, how little it drops, and what it does to patrols and the horde. The fight's Director reads these (see its AlertTuning).

How a mission's station alert level builds up (its template's "alert"): how it rises over time and with noise, how little it drops, and what it does to patrols and the horde. The fight's Director reads these (see its AlertTuning).

public AlertSettings(float PerMinute = 0.05, float PerFightSecond = 0.003, float PerNoiseSecond = 0.002, float HackJump = 0.15, float Keep = 0.75, float Fade = 0.01, float Aggression = 2.5, float PatrolBonus = 2, float CapBonus = 3, float HordeAt = 0.6, float Elevated = 0.35, float High = 0.65, float Lockdown = 0.9, float SweepRooms = 6, float NudgeSeconds = 45, float BackOffSeconds = 25)

Parameters

PerMinute float

How much alert rises per minute on the level.

PerFightSecond float

How much alert rises per second a soldier is fighting.

PerNoiseSecond float

How much alert rises per second for each pumping tank or each inbound pod drone.

HackJump float

How much alert jumps immediately when the hack starts.

Keep float

The fraction of its peak that alert never drops below.

Fade float

How much alert drops per second while everything is quiet.

Aggression float

At full alert, the Director's wait times are divided by this.

PatrolBonus float

At full alert, this many extra soldiers per patrol.

CapBonus float

At full alert, this many extra patrol soldiers can be alive at once.

HordeAt float

From this alert level on, the run's hordes can show up while infiltrating.

Elevated float

Alert level for the first stage (amber light, the PA).

High float

Alert level for high alert.

Lockdown float

Alert level for lockdown (red light, patrols go out without waiting).

SweepRooms float

At full alert, how many extra rooms a hunter sweeps (two when calm).

NudgeSeconds float

While calm, seconds between nudges that move the garrison toward the squad's area.

BackOffSeconds float

Seconds hunters can crowd the squad without a fight before they get pulled off.
