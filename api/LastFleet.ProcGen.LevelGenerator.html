Generates a level from a seed (design doc, "Procedural level generation"). Pass 1 builds the mission graph from the template, pass 2 lays out the biome's room modules, and pass 3 assembles the mesh and places the fight. The same seed, template and library always give the same level on every machine, so co-op peers only send the seed.

Remarks

A template can ask for rooms built from the seed (ParametricRoom), which are added to the library for that level only. Each deck also gets halls built in its theme (ParametricHall), offered alongside the kit's corridors on that deck. The station's fixtures (tanks, the reservoir, the airlock's fittings) are prop models from props, as the template names them. The designers' procgen data (data, or just the built-in tags if none is given) tags each room.

Remarks

If the template requires reservoirs and the level can't place the minimum it asks for, the level is regenerated from seeds derived from this one (the same on every machine), up to RemakeAttempts times. The attempt that places the most reservoirs is kept, and its Remade says how many retries it took.
