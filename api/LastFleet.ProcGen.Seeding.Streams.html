The random streams a level is generated from: one per stage, one per room in a stage, and one per rule for a room. Each stream depends only on the level's seed and its own keys, never on what another stream drew. So changing one room's rules leaves every other room, and every other stage, unchanged.

Remarks

Each stage is keyed by a fixed name rather than its position in GenerationStage, so stages can be added or reordered without changing any stream. Rules are keyed by their ids. Code written before these streams existed (the mission graph, the layout solver, the dressing) keeps its own named streams, so the levels it makes don't change.
