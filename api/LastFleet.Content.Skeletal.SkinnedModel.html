A character made in Blender on a rig (content/characters, see docs/blender/rigs.md). Its meshes are skinned to the rig's skeleton and stored as flat triangles in the bind pose, each vertex with its four joints and weights, so the GPU can skin it every frame using the pose the game provides.

Skin(ReadOnlySpan<Matrix4x4>, Span<MeshVertex>)

Skins the model on the CPU the same way the GPU does, producing flat-shaded triangles for a preview. It uses the matrices from Skin(in Matrix4x4, Span<Matrix4x4>), and each vertex is the weighted sum of its joints' matrices applied to it. into gets one vertex for each of Vertices, with each face lit by its own normal. Doesn't allocate.
