One skinned body drawn this frame. Holds its mesh (AddSkinnedMesh(ReadOnlySpan<SkinnedVertex>)), where its joint matrices start in the frame's SkinMatrices, a tint, and whether it's the viewer's own body. The viewer's body is drawn like the gun in hand, in front of the world, so it never clips through a wall the player is standing against.

Parameters

Mesh int

The mesh ID returned by AddSkinnedMesh(ReadOnlySpan<SkinnedVertex>).

FirstMatrix int

Index of the first joint matrix in the frame's matrices. The vertices' joint indices are relative to it.

Tint Vector4

rgb is blended over the lit color by a (for example a hit flash), same as for level parts.

Near bool

The viewer's own body in first person. It's drawn in the near end of the depth range, like the view model, but still casts its shadow.

CutRadius float

For the viewer's own body: anything within this many meters of the eye isn't drawn (the shadow stays whole), so the shoulders and chest never fill the view, whatever the pose. A body cut this way is drawn without a tint. 0 means no cut.
