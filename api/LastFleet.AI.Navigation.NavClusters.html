A coarse map over a NavGrid for long paths. Each 4 m square of each floor is split into clusters of walkable cells that connect inside the square, and clusters are linked wherever a link or a drop crosses from one to the next.

Remarks

A search over clusters (a few thousand in a big level, versus hundreds of thousands of cells) finds which ones a path goes through, and the cell search then stays inside those. That crosses a whole deck in a few thousand steps instead of visiting every reachable cell.

Any cell in a cluster can reach any other without leaving it (they're connected by straight links inside the square), so a chain of linked clusters always contains a path.

Built of the floor as the grid was built (WasBuiltWalkable(int)), and never changed after: it's part of the grid's NavTopology, shared by every Pathfinder on it. The search over it, with its memory, is each pathfinder's own (LastFleet.AI.Navigation.CorridorSearch).
