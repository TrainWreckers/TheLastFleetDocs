Remarks

Triangles are grouped into Parts, one per source node. Physics builds one box collider per part, and ray hits report which part they hit, so targets and other special pieces are looked up by part.

Exceptions

ArgumentException

The index count isn't a multiple of three, an index is out of range, or a part isn't a run of whole triangles inside the index list.
