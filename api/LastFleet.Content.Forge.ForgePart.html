Remarks

If there are any, the triangles are only drawn (ShapeNode) and these boxes are only collided with (SolidNode(int)), which is what level collision expects (docs/blender/props.md).

Detailing

When true, anything added now is detail (Detail): small things shown on your own gun but left off other players' guns, to keep the number of moving triangles per frame down.

public bool Detailing { get; set; }

Far

The part's far version, used for other players' guns: the same shapes without bevels or detail, with round shapes using fewer sides (ForgeRecipes builds it). It's drawn instead of the normal mesh. If empty, the normal mesh is drawn without its detail.
