Namespace LastFleet.ProcGen.Networks

Classes

LaidNetwork

A network as laid in a level, for designers to inspect (the Studio preview): the route it took, what each section runs along, its cost, and the cheapest route it didn't take (Alternative(LaneGraph, NetworkSpec, NetworkRoute, IReadOnlyList<int>, LaneUsage?)). The alternative is only computed the first time it's asked for.

LaneGraph

The graph of places a level's networks can run (LaneKind). That covers a band along every room's walls above the doorway lintels, a higher lane along them (under the ceiling, or up a tall room's wall), a standoff lane offset from the wall to get past whatever already runs along it, straight spans across open ceilings from wall to wall, risers between these and up tall rooms' walls, crossings through walls and floors rooms share (including next to a doorway) and through doorway lintels, and the empty cells enclosed by rooms (service cells).

LaneUsage

Tracks which lanes of a level's LaneGraph the networks have used so far, and by which kind. A lane only carries networks of one kind, side by side (each new one BundleOffset further out). So networks of the same kind bundle together, and a different kind finds the lane taken.

NetworkCosts

What a network's route costs for each kind of lane (LaneKind). Costs are integers so every machine finds the same route. They're charged per meter along a lane, once for each wall or lintel passed through, and once for each bend. A higher cost keeps routes off that kind of lane unless nothing cheaper gets there.

NetworkLimits

Limits on how far a network can run in places where a pipe is most in the way.

NetworkRoute

A network's path through a level's LaneGraph, found by NetworkRouter: the nodes it passes in order, the edges between them, and its total cost.

NetworkRouter

Finds a network's cheapest route through a level's lanes (LaneGraph) using A*. Costs are integers (NetworkCosts) and ties are broken by node index, so every machine finds the same route.

NetworkSpec

A type of network that connects things in a level (a fuel feed, a water main, a cable run). It defines what the route costs for each kind of lane, how far it can cross open ceiling or run through empty cells, and what its pipe looks like. Loaded from networks.json (Networks).

PipeLook

What a network's pipe looks like.

LaneKind

What a lane in a LaneGraph runs along or through. Each kind is priced by a network's NetworkCosts. Every lane is straight, either horizontal or vertical, along one of the level's axes.
