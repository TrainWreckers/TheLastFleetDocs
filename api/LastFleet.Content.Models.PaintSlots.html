The naming rules for model materials and color (see docs/blender/props.md and docs/blender/weapons.md). A material named Paint_<Name> is a PaintSlot whose color is set by the data, defaulting to the material's own color. A few names are colored by the game (a prop's Glint, a gun's Body). Any other material keeps its own color.

Remarks

It catches: a paint slot with no name; a slot name that isn't letters, digits and underscores; a slot named after one of this folder's game colors (Paint_Glint on a prop); a game color name from the other folder (a prop's Body isn't the manufacturer's finish, although Paint_Body is a fine slot); or a game color name with different capitalization (glint). Each of these would silently not get colored as intended.
