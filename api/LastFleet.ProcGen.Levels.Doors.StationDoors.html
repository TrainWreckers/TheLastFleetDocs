How the station's doors are built and how they look. Each is a dark slab filling the doorway, with both faces plated as two leaves in the paint for the door's kind (Plates(in DoorLayout, int, List<DoorPlate>)). A lamp above it is red (amber for the lockdown) and turns green once it's open, and a gate's post gets a keycard reader or release panel. The client slides the same plates apart as it opens. The top of the slab above the leaves stays as a transom, like a doorway's lintel.
