Interface ITransport

Namespace
LastFleet.Networking.Transport
Assembly
LastFleet.Networking.dll

Moves messages between a host and its clients. The game only talks to this interface, so the transport can be RakNet (direct IP, for playtests), an in-memory network (tests, soak runs), or Steam networking later, without changing anything above it.

public interface ITransport : IDisposable
