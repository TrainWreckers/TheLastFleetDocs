Remarks

It picks a free voice. If the cue already has as many voices as it's allowed, it reuses that cue's oldest voice. If no voice is free, it takes the oldest voice with the lowest priority, as long as that priority isn't higher than the new sound's (so a footstep never cuts off a gunshot). Loops are never taken.
