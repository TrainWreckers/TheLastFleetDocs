Remarks

The projection is reverse-Z with an infinite far plane: depth is 1 at the near plane and falls towards 0 at infinity, so a 32-bit float depth buffer keeps its precision far into the distance. Depth tests use Greater and the depth buffer clears to 0.

Clip space has +Y up. The renderer flips the viewport (negative height) to match Vulkan's +Y-down framebuffer, which also keeps glTF's counter-clockwise front faces counter-clockwise.
