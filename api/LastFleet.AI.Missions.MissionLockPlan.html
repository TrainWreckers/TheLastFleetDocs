Remarks

A lock opens in one of these ways:

  • Its keycard.
  • The hack finishing (OpensOnHack). Used for the gate to the last zone, the way out.
  • A timer (OpensAt, seconds into the mission). Used for the airlock's inner door, id 0, which no keycard opens.
  • Someone standing at OpensFrom, on the side it opens from. Used for one-way shortcuts, with no keycard.
