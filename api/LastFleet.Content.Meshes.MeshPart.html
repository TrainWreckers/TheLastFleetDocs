A named range of triangles inside a MeshData. It's one glTF node, such as one wall or one crate.

public MeshPart(string Name, int FirstIndex, int IndexCount, PartUsage Usage = PartUsage.Both, PartShape Shape = PartShape.Box)

Parameters

Name string

The node name, or a generated one.

FirstIndex int

Position of the part's first index in Indices.

IndexCount int

Number of indices, three per triangle.

Usage PartUsage

Drawn, collided with, or both. A node named _NoCollision is only drawn (the steps of a staircase), and one named _CollisionOnly is only collided with (the ramp under them), so stairs feel like a smooth slope.

Shape PartShape

The body it's collided with, if it has one: a box fitted to it (the default, which its triangles have to form), its triangles as they are, or an upright cylinder around them (PartShape).
