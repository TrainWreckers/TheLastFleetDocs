Namespace LastFleet.Content.Reloads

Classes

ReloadLibrary

The reload definitions (content/defs/reloads.json; see docs/plans/weapons.md phase 4). For each frame model, it holds the steps its guns' reloads go through, if any. A frame without one keeps the body's own reload clip, with the hand off the gun.

ReloadScript

How guns of certain frames reload (content/defs/reloads.json, ReloadLibrary): the left hand's steps over the course of the reload, and where the magazine is during each one.

ReloadStep

One step of a reload (ReloadScript): the hand moves to a point and gets there by a given fraction of the reload.

Structs

ReloadPose

The state of a reload at one point in time, as returned by Sample(float, bool). It holds the two points the hand is moving between, how far along it is (eased, 0 to 1), and where the magazine is.

MagazinePlace

Where the magazine is during a reload step (ReloadStep).

ReloadPoint

Where a reload step moves the left hand to (ReloadStep).
