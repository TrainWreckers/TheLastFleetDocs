How a level's loops get made, beyond how many each zone gets (Loops). Sets how far apart in the room tree a loop's two ends have to be, how long a corridor routed around corners for a loop can be, what fraction of rooms should end up on a loop, the most that should be dead ends, and how many one-way shortcuts cross each gate between zones. Loops keep getting added until both the loop and dead-end targets are met, or no more fit.

Remarks

A one-way shortcut is a door between two rooms in neighboring zones. It stays shut until someone stands at it on the deeper zone's side, and it only opens from there. So it never lets the squad past a gate before they have its keycard. It only gives them a short way back once they're through (OpensFrom).

Parameters

MinDistance int

The fewest steps through the room tree (corridors count) between a loop's two ends.

MaxRouteCells int

The longest corridor routed around corners to close a loop, in cells.

Share float

The fraction of rooms (not counting closets) that should be on a loop, 0 to 1. 0 adds no loops for this target.

OneWayPerGate (int Min, int Max)

The min and max number of one-way shortcuts across each gate between zones.

DeadEndShare float

The most rooms (not counting closets) that should be dead ends, as a fraction from 0 to 1. Loops from dead ends are added until it's met or no more fit. 1 adds no loops for this target.
