Enum BodyAbility

Namespace
LastFleet.AI.Behavior
Assembly
LastFleet.AI.dll

Something a soldier's body has to be able to animate for its behavior to work. Behaviors never name animations, but a behavior that throws grenades needs a body that can visibly throw.

public enum BodyAbility : byte

Fields

Fire = 0

Fires its gun, with the shot's recoil (the graph's fire action).

Reload = 1

Swaps its gun's magazine (the graph's reload action).

Throw = 2

Throws a grenade (the graph's throw action).

Crouch = 3

Crouches, behind low cover or in the open.

Lean = 4

Leans out around cover to fire, then back in.

BlindFire = 5

Fires blind over or around cover, with the gun up and the head down.

Remarks

A body type's animation graph (content/anim) lists what it supports under capabilities. A behavior's needs come from the actions in its tree (Needs). If an enemy variant's behavior needs something its body can't animate, that's reported as a problem when the data is loaded. In the data, each value is written the way Name(BodyAbility) returns it (for example blindFire).
