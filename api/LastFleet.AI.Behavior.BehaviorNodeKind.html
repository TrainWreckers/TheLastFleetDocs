The type of a node in a soldier's behavior tree: how it decides whether it succeeds, and what it does.

public enum BehaviorNodeKind : byte

Fields

Selector = 0

Tries its children in order and succeeds on the first one that succeeds. Fails if none do.

Sequence = 1

Runs its children in order as long as they succeed. Fails at the first one that fails.

All = 2

Runs every child regardless of result, then succeeds. Used for things done every update alongside the main choice.

Not = 3

Succeeds when its single child fails, and fails when it succeeds.

Awareness = 4

Succeeds while the soldier's awareness matches the one named (idle, alerted, engaging, hunting, searching).

Check = 5

Succeeds while one of the combat scoring inputs passes the given comparison (for example range > 20).

HasCover = 6

Succeeds if the level has cover points to fight from.

SquadAlive = 7

Succeeds while the number of squad members still standing passes the given comparison.

DistanceToEnemy = 8

Succeeds while the distance to the enemy's last known position passes the given comparison, in meters.

SeesEnemy = 9

Succeeds while the soldier can see an enemy.

Intent = 10

Succeeds while the soldier's intent matches the one named (hold, advance, push, fall back).

Action = 11

Runs one of the soldier's actions (BehaviorAction).
