Namespace LastFleet.AI.Behavior

Classes

BehaviorTree

A compiled soldier behavior tree. Holds the nodes reachable from the root, root first, with each node's children stored next to each other in Children.

BodyAbilities

Data names for BodyAbility values, and which abilities each behavior tree action needs.

SoldierBehavior

How a type of soldier behaves (content/defs/ai/<id>.json). Holds its behavior tree (what it does from moment to moment, from roaming to fighting) and the scoring the tree's "choose intent" action uses in a fight (hold, advance, push or fall back; UtilityModel).

Structs

BehaviorNode

One node of a compiled behavior tree.

Enums

BehaviorAction

The actions a soldier can perform, each one a leaf of its behavior tree. The game decides how each is done (the soldier's movement, aim and tactics); the tree decides when.

BehaviorNodeKind

The type of a node in a soldier's behavior tree: how it decides whether it succeeds, and what it does.

BodyAbility

Something a soldier's body has to be able to animate for its behavior to work. Behaviors never name animations, but a behavior that throws grenades needs a body that can visibly throw.
