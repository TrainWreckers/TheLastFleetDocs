Turns a room's scene, as written by a built room or hall (ParametricRoom, ParametricHall), into a RoomModule. It also checks the scene against the kit's rules, so a mistake is reported by name when the room is built instead of showing up as a broken level.

Remarks

What the scene contains (the same nodes a glTF file would have, back when rooms were made in Blender):

  • Geometry: every mesh node. The footprint is its bounds on the ground plane, which must be whole 4 m cells. The module is shifted so the footprint starts at its origin. The top of the floor is at y = 0.
  • A node named Module whose custom property tags lists the roles it can fill.
  • Markers, as nodes without a mesh (Blender empties): Door in the middle of a cell edge, one per doorway; Spawn_Soldier and Spawn_Player (facing their local -Z, which is an empty's +Y in Blender); Crate_Ammo; and Marker_Key, Marker_Terminal, Marker_Extraction. Names can have a suffix (Spawn_Soldier.001, Spawn_Soldier2).
