The parts fitted to a weapon to replace the ones it rolled, one per part slot (barrel, magazine, stock, optic, module, muzzle, grip, trigger, in that order). An empty slot keeps the rolled part. This is part of a WeaponIdentity, so a weapon a player has modified still only takes a few bytes to send.
