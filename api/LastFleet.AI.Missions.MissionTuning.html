Parameters

KeyReach float

How close (horizontally) a standing player has to get to pick up a keycard.

DoorReach float

How close a player holding the keycard has to get to open a locked door.

TerminalReach float

How close to the terminal Interact starts the hack.

StartSeconds float

How long Interact has to be held to start the hack.

HackSeconds float

How long the hack takes. It only counts down while the room is held.

HoldRadius float

How far from the terminal still counts as holding its room.

HoldHeight float

How far up or down still counts as the same room. Also used for the extraction point.

Waves int

How many reinforcement waves the hack brings.

WaveBase int

Soldiers in every wave, regardless of squad size.

WavePerPlayer int

Extra soldiers per wave for each player.

FirstWaveDelay float

Time from the start of the hack to the first wave.

WaveInterval float

Time between waves.

SpawnClearance float

No reinforcement spawns (and no closet opens) within this distance of a standing player.

ClosetOpenSeconds float

Minimum time a closet door stays open once soldiers are inside.

WaveHoldSeconds float

Longest a wave waits while the Director is holding waves back (because the squad is under heavy pressure).

ExtractRadius float

How close to the extraction point everyone has to stand.

ExtractSeconds float

How long everyone has to stand there together to extract.

AirlockSeconds float

How long the airlock takes to cycle at the start before its inner door opens, counted once every player is aboard.

EarlySeconds float

How long the squad has to hold Interact together at the airlock to leave early.

EarlyRadius float

How close to the hatch everyone has to stand to leave early.

BoardingSeconds float

The longest the insertion waits for players still loading the level before it cycles anyway, so one stuck client can't hold the squad forever.

PodSeconds float

How long someone inside an escape pod has to hold Interact to launch it.

PodRadius float

How near the middle of a pod's floor counts as inside it.
