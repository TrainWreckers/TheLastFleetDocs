What each model is collided with (ColliderKind), read from colliders.json next to the models (content/props). Kept apart from the models themselves and from the rules that place them, since the same model is placed by many rules.

Remarks

The file gives a default for every model in a glTF file ("files": { "furniture": "mesh" }) and overrides for single models ("models": { "furniture/Barrel": "cylinder" }). A model in neither is Authored. Kinds are written in lowercase: authored, mesh, box, cylinder, none.

Reading never fails: an entry with a problem is left out and the problem reported, so the rest still apply.
