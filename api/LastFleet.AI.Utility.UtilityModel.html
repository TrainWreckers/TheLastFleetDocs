How soldiers decide what to do in a fight (a behavior's scoring, content/defs/ai/soldier.json): utility scoring of hold, advance, push and fall back. Each intent's score is its base plus its terms, times its factors (IntentRule), times the squad personality's scale for it. The highest score wins, with the current intent getting Stickiness added on top.

Remarks

Built from data, so designers can tune and add considerations without touching code. Default is the shipped file, embedded in the AI assembly, so a world without the content folder (tests, tools) plays the same. Scoring is pure, deterministic and doesn't allocate.
