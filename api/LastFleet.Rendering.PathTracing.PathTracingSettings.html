How the path tracer works (PathTraced). Every setting applies on the next frame, with no restart: the render size changes with Dlss, which waits for the frames in flight and makes the path tracer's images anew.

public PathTracingSettings(int Bounces = 2, int SamplesPerPixel = 1, PathDenoiser Denoiser = PathDenoiser.RayReconstruction, DlssMode Dlss = DlssMode.Quality, bool RadianceCache = true)

Parameters

Bounces int

How many times a path bounces after the surface seen (1 to MaxBounces). One is the light bounced once, as the hybrid renderer's ray bounce gives; each more adds light from further round, and noise.

SamplesPerPixel int

Paths traced from each pixel each frame (1 to MaxSamples).

Denoiser PathDenoiser

What takes the noise out.

Dlss DlssMode

The DLSS mode: how far below the display's resolution to render.

RadianceCache bool

End each path into its room's bounce light (the engine's radiance cache, as RTXPT ends paths into SHaRC): the light from every bounce after the last, at no cost. Off is unbiased but darker and noisier at few bounces.
