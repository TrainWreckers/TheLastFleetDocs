Parameters

ShadowRays int

Shadow rays per pixel per frame (ray_shadow_trace.slang).

BounceEveryOther bool

If true, the bounce traces half its pixels each frame in a checkerboard that flips every frame, and the other half is reused from earlier frames (ray_indirect_trace.slang, ray_shadow_temporal.slang).

BounceReach float

How far a bounce ray travels, in meters. A ray that hits nothing uses the room's bounce light at its end point.

BounceFilterPasses int

Number of filter passes over the bounce (must be even).

OcclusionRays int

Occlusion rays per pixel per frame (ray_occlusion_trace.slang).
