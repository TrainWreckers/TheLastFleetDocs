Remarks

A file dropped into either folder gets picked up without any code changes. A file that fails to load is kept as an empty entry with the reason (Problem), so the rest still load.

ModelLibrary(IEnumerable<ModelFile>, ModelColliders?)

Builds the library from files that are already loaded (LoadFile(string, ModelKind)), with what each model is collided with (Colliders; none given, every model is Authored).

Remarks

Two files with the same name (one in each folder), or two objects with the same name in one file (Blender's "Crate.001" next to "Crate"), can't both have that id. The first one is kept and the other is reported as a problem.
