Wraps a real transport in a simulated bad network, for testing co-op over a LAN as if it were over the internet (--net-sim). Every message in either direction is delayed by the latency plus up to the jitter, and unreliable messages this machine sends are dropped at the given rate.

Remarks

Latency is added in each direction, so --net-sim 75 on one machine adds about 150 ms to the ping. Only outgoing unreliable messages are dropped: incoming ones can't be told apart from reliable ones here, and reliable messages must never be lost (or reordered, so they're released in order). It allocates per message, which is fine for a test tool.
