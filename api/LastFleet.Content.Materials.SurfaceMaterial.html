A material in the library (content/defs/materials.json, see MaterialLibrary). It describes how a surface reacts to light. The color comes from the model; the material says whether it's paint or bare metal, rough or polished.

public SurfaceMaterial(string Id, string Name, float Roughness, float Metalness, bool Smooth = false, float Grime = 0, bool Emissive = false, Vector3? Color = null, SightWindow Sight = SightWindow.None, bool Space = false, bool Outside = false)

Parameters

Id string

The id models use to refer to it (painted_metal).

Name string

The display name in Studio and Blender ("Painted metal").

Roughness float

0 is a mirror, 1 is chalk. Controls how wide and dim the highlights are.

Metalness float

0 for paint, plastic, rubber and glass. 1 for bare metal, which has no diffuse light and tints its reflections with its color.

Smooth bool

If true, highlights follow a smoothed surface while the lighting stays faceted.

Grime float

How much station grime it picks up, 0 to 1.

Emissive bool

If true, the color is light it gives off instead of a surface lit by other lights.

Color Vector3?

A fixed color that overrides the model's color, or null to use the model's.

Sight SightWindow

Marks sight glass (a red dot or holographic sight). The glass is clear except for the reticle, which is drawn in the model's color where the eye looks along the aim, like a real one projected at infinity (SightWindow). None for any other surface.

Space bool

A window onto space: drawn as the sector's sky seen through it (SkyLibrary), whatever its color, and never what's behind it.

Outside bool

On the outside of a ship or station, out in space: lit by the sector's sun (SkyLibrary), not by a room's sky fill, and seen through no haze but the room's the view comes from.
