Runs an effect (EffectDefinition) on a player. It can check whether using the effect now would do anything, and it applies the effect's actions in order. Anything that needs the world (like dropping a pod) is handed back for the caller to do.

Remarks

Healing only counts when hurt, armor only when below its max, a shield only when it would end up fuller, refilling only when some weapon has room for more rounds, and calling a pod only while a mission is still going (missionOn). A stat change and a device always count (the stat change starts or is renewed). A sound or a flash on its own isn't useful, but an effect that does nothing else can always be used.
