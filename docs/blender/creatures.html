Modeling and animating creatures in Blender

The horde's bodies are models made and animated in Blender. The game draws hundreds of them at once on the GPU, each on its own frame of its own animation. The swarmling is the first one: content/models/swarmling.gltf.

So you want to edit or replace it? This page walks you through it in Blender. Reshaping the body or reworking the animations doesn't need any code changes!

The file you start from is the grey-box swarmling: a few faceted pieces, each skinned to one bone, with simple keyed animations. tools/blender/generate_swarmling.py made it. Replace it however you like, but don't run that script again over your work, because it'd put the starter model back.

Setting up

  1. Install the add-on: Edit > Preferences > Add-ons > Install from Disk, and pick tools/blender/lastfleet_creatures.py. Enable Last Fleet Creatures. Its tools are in the 3D view's sidebar (N), on the Last Fleet tab, in the Creature panel.
  2. Open the model with the panel's Open button, not File > Import. Why? It sets the scene to 30 frames a second first, which is the rate the game plays animations at. If you import the model into Blender's default 24 fps scene, its keys end up between frames, and exporting it would cut the end off each animation.
  3. Folder is where Export writes to (content/models), and Creature is the file name (swarmling). Open fills in both for you.

What the game reads

What How
The rig One armature. The bones can be anything. The starter's are named Root, Hips, Chest, Head, Abdomen, the legs (FrontLeg.L.Upper and so on) and the blades (Arm.L, Blade.L).
The near body Meshes skinned to the armature (an Armature modifier, vertex groups named after bones, at most four bones per vertex), with any name that doesn't end in _LOD1
The far body Meshes named <anything>_LOD1. They're drawn beyond 22 m, and for shadows. Give it about a third of the triangles. If there isn't one, the near body gets drawn at every distance.
Animations Actions, found by name (see below). Each one is a frame range starting at 0, with keys on whole frames at 30 fps
Shading Flat: each face is lit by its own normal. Smooth shading and custom normals are ignored.
Colors A material's Base Color. A material named Glow glows in the Choir's violet and dims as the creature dies.
Surface materials How each material reacts to light, picked with the Last Fleet Materials add-on (materials.md). The swarmling's chitin is plastic and its Glow is emissive.
Size and facing Meters. The creature faces +Y (the game's forward), +Z is up, and its feet are on the origin.

Hit volumes. Here's the catch: where a shot hits is decided in code, not by the mesh (Swarmling in src/LastFleet.Simulation).

  • The body is a low capsule 0.72 m tall.
  • The head is a sphere with a 0.17 m radius, 0.42 m forward and 0.6 m up. A shot there counts as a precision hit.

So keep the head and body roughly where they are, or ask a programmer to change the numbers to match.

The animations

Action Played Notes
Run A loop, while it runs One stride. The game plays one loop every 1.1 m covered, so the feet keep pace with the ground at any speed. Make it run in place, since the game moves the body.
Idle A loop, standing
WindUp Once, before the bite 0.3 s, the same as the game's wind-up. This is the telegraph players react to, so make it big and readable!
Bite Once, when the wind-up ends Starts from the WindUp's last pose.
Stagger Once, when a heavy hit knocks it back
Death Once, when it dies It holds the last pose, then the game darkens it and sinks it into the floor.

The game fades from one animation to the next over 0.12 s. A couple of gotchas:

  • Loops have to end where they start. Key the last frame the same as the first.
  • Step through them. Use the Play action buttons in the panel to watch each one.

Checking and exporting

Check reports anything the game wouldn't read:

  • no armature, or more than one;
  • a mesh with no Armature modifier;
  • unweighted vertices, or ones with more than four bones;
  • a missing action;
  • a scene not at 30 fps;
  • an action starting or ending between frames.

Export runs the check first, then writes one .gltf with the buffers inside it (no .bin) and every action included. Commit that file. The game bakes it when the first level loads and keeps it, so restart the game to see your change.

To see it in the game, run LastFleet --horde 30 (or use F3 > AI > Horde of 30) and let them come to you... they will.
